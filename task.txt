================================================================================
GRAMMAR PRACTICE ASSISTANT — ПОЛНАЯ ИНСТРУКЦИЯ ПО РЕАЛИЗАЦИИ
================================================================================

Стек:
- Pydantic AI (агенты, типизированные ответы)
- Llama 3.3 70B Versatile через Groq
- LanguageTool (детекция грамматических ошибок)
- spaCy en_core_web_sm (структурный анализ)
- LanguageTool locale: en-US
- Менеджер пакетов: pip + requirements.txt

Пользователь: русскоязычный, B2, хороший вокабуляр, слабая интуиция грамматики.
Объяснения и упражнения: на английском.

ШАГ 0. ПОДГОТОВКА ОКРУЖЕНИЯ

0.1. Получить Groq API key
---------------------------
Зарегистрируйся на https://console.groq.com, создай API key.
Llama 3.3 70B Versatile на Groq бесплатна в рамках rate limits
(~30 RPM, ~14400 RPD — проверь актуальные на странице limits).

0.2. Переменные окружения
--------------------------
Добавь в .env (в корне проекта):

    GROQ_API_KEY=gsk_...

Убедись, что .env в .gitignore.

0.3. Зависимости
-----------------
Добавь в requirements.txt:

    pydantic-ai-slim[groq]>=0.0.14
    pydantic>=2.0
    pydantic-settings>=2.0
    language-tool-python>=2.8
    spacy>=3.7
    python-dotenv>=1.0

Установка:

    pip install -r requirements.txt
    python -m spacy download en_core_web_sm

0.4. Java для LanguageTool
---------------------------
LanguageTool — Java-приложение. При первом запуске скачает ~200MB в
~/.cache/language_tool_python/. Нужна Java 8+.

    Ubuntu/Debian: sudo apt install default-jre
    macOS:         brew install openjdk
    Windows:       https://adoptium.net

Если Java ставить не хочешь — есть режим публичного API
(language_tool_python.LanguageToolPublicAPI), он медленнее и с лимитами.
Покажу переключение в коде.

from enum import Enum
from typing import Optional
from pydantic import BaseModel, Field


class ExerciseType(str, Enum):
    ERROR_CORRECTION = "error_correction"
    CONDITIONAL = "conditional"
    TENSE_TRANSFORMATION = "tense_transformation"
    GERUND_INFINITIVE = "gerund_infinitive"
    REPORTED_SPEECH = "reported_speech"
    MODAL_DEDUCTION = "modal_deduction"
    ARTICLES = "articles"
    INVERSION = "inversion"
    PASSIVE_VOICE = "passive_voice"
    PREPOSITIONS = "prepositions"
    SENTENCE_COMBINING = "sentence_combining"
    PHRASAL_VERBS = "phrasal_verbs"


class Exercise(BaseModel):
    id: str = ""
    exercise_type: ExerciseType
    instruction: str
    prompt: str
    expected_answer: str
    grammar_topic: str
    metadata: dict = Field(default_factory=dict)


class GrammarError(BaseModel):
    message: str
    category: str
    offset: int
    length: int
    suggested_replacements: list[str] = Field(default_factory=list)


class TokenInfo(BaseModel):
    text: str
    pos: str
    tag: str
    dep: str
    lemma: str
    morph: str


class SentenceAnalysis(BaseModel):
    tokens: list[TokenInfo]
    detected_tenses: list[str]
    has_inversion: bool
    has_passive: bool


class StructureDiff(BaseModel):
    tense_changed: bool
    tenses_before: list[str]
    tenses_after: list[str]
    inversion_changed: bool
    passive_changed: bool


class ValidationResult(BaseModel):
    exercise_id: str = ""
    is_correct: bool
    user_answer: str = ""
    correct_answer: str = ""
    rule_name: str
    explanation: str
    what_to_review: str = ""
    grammar_errors: list[GrammarError] = Field(default_factory=list)
    matched_alternative: Optional[str] = None

import language_tool_python
from grammar_assistant.config import config
from grammar_assistant.models import GrammarError

_tool = None


def _get_tool():
    global _tool
    if _tool is None:
        # Локальный режим (требует Java):
        _tool = language_tool_python.LanguageTool(config.language_tool_locale)
        # Без Java (медленнее, с лимитами):
        # _tool = language_tool_python.LanguageToolPublicAPI(config.language_tool_locale)
    return _tool


def check_grammar(text: str) -> list[GrammarError]:
    tool = _get_tool()
    matches = tool.check(text)
    return [
        GrammarError(
            message=m.message,
            category=m.category,
            offset=m.offset,
            length=m.errorLength,
            suggested_replacements=m.replacements[:5],
        )
        for m in matches
    ]


def close_tool():
    """Вызывай при остановке приложения, чтобы убить Java-процесс."""
    global _tool
    if _tool is not None:
        _tool.close()
        _tool = None

import spacy
from grammar_assistant.config import config
from grammar_assistant.models import SentenceAnalysis, TokenInfo

_nlp = None


def _get_nlp():
    global _nlp
    if _nlp is None:
        _nlp = spacy.load(config.spacy_model)
    return _nlp


def analyze_sentence(text: str) -> SentenceAnalysis:
    nlp = _get_nlp()
    doc = nlp(text)

    tokens_info = [
        TokenInfo(
            text=t.text, pos=t.pos_, tag=t.tag_,
            dep=t.dep_, lemma=t.lemma_, morph=str(t.morph),
        )
        for t in doc
    ]

    return SentenceAnalysis(
        tokens=tokens_info,
        detected_tenses=detect_verb_tenses(doc),
        has_inversion=detect_inversion(doc),
        has_passive=detect_passive(doc),
    )


def detect_verb_tenses(doc) -> list[str]:
    """
    Определяет tense/aspect конструкции в предложении.

    Эвристика: для каждого ROOT/conj глагола смотрим его aux/auxpass-цепочку
    плюс собственные морфологические признаки. Возвращаем человекочитаемые
    названия времён.
    """
    found = []

    for token in doc:
        # Интересуют только финитные глаголы или причастия в роли глагола
        if token.pos_ not in ("VERB", "AUX"):
            continue
        # Чтобы не дублировать вспомогательные глаголы, берём только "главу" клаузы
        if token.dep_ in ("aux", "auxpass"):
            continue

        # Собираем все aux/auxpass-зависимости
        aux_children = [c for c in token.children if c.dep_ in ("aux", "auxpass")]
        aux_lemmas = [c.lemma_.lower() for c in aux_children]
        aux_tags = [c.tag_ for c in aux_children]

        main_tag = token.tag_  # VB, VBZ, VBP, VBD, VBN, VBG
        main_lemma = token.lemma_.lower()

        # --- Future Perfect Continuous: will have been Ving ---
        if (("will" in aux_lemmas or "shall" in aux_lemmas)
                and "have" in aux_lemmas
                and "be" in aux_lemmas
                and main_tag == "VBG"):
            found.append("Future Perfect Continuous")
            continue

        # --- Future Perfect: will have V3 ---
        if (("will" in aux_lemmas or "shall" in aux_lemmas)
                and "have" in aux_lemmas
                and main_tag == "VBN"):
            found.append("Future Perfect")
            continue

        # --- Future Continuous: will be Ving ---
        if (("will" in aux_lemmas or "shall" in aux_lemmas)
                and "be" in aux_lemmas
                and main_tag == "VBG"):
            found.append("Future Continuous")
            continue

        # --- Future Simple: will V ---
        if ("will" in aux_lemmas or "shall" in aux_lemmas) and main_tag == "VB":
            found.append("Future Simple")
            continue

        # --- Past Perfect Continuous: had been Ving ---
        if "have" in aux_lemmas and "VBD" in aux_tags and "be" in aux_lemmas and main_tag == "VBG":
            found.append("Past Perfect Continuous")
            continue

        # --- Past Perfect: had V3 ---
        if "have" in aux_lemmas and "VBD" in aux_tags and main_tag == "VBN":
            found.append("Past Perfect")
            continue

        # --- Present Perfect Continuous: have/has been Ving ---
        if "have" in aux_lemmas and ("VBZ" in aux_tags or "VBP" in aux_tags) \
                and "be" in aux_lemmas and main_tag == "VBG":
            found.append("Present Perfect Continuous")
            continue

        # --- Present Perfect: have/has V3 ---
        if "have" in aux_lemmas and ("VBZ" in aux_tags or "VBP" in aux_tags) \
                and main_tag == "VBN":
            found.append("Present Perfect")
            continue

        # --- Past Continuous: was/were Ving ---
        if "be" in aux_lemmas and "VBD" in aux_tags and main_tag == "VBG":
            found.append("Past Continuous")
            continue

        # --- Present Continuous: is/am/are Ving ---
        if "be" in aux_lemmas and ("VBZ" in aux_tags or "VBP" in aux_tags) \
                and main_tag == "VBG":
            found.append("Present Continuous")
            continue

        # --- Modal + perfect: must/might/could/should have V3 ---
        modal_lemmas = {"can", "could", "may", "might", "must", "shall",
                        "should", "will", "would", "ought", "need"}
        modals_in_aux = [l for l in aux_lemmas if l in modal_lemmas]
        if modals_in_aux and "have" in aux_lemmas and main_tag == "VBN":
            found.append(f"Modal Perfect ({modals_in_aux[0]} have V3)")
            continue
        if modals_in_aux and main_tag == "VB":
            found.append(f"Modal ({modals_in_aux[0]})")
            continue

        # --- Past Simple ---
        if main_tag == "VBD":
            found.append("Past Simple")
            continue

        # --- Present Simple ---
        if main_tag in ("VBZ", "VBP", "VB"):
            found.append("Present Simple")
            continue

    return found


def detect_inversion(doc) -> bool:
    """
    True если предложение начинается с отрицательного наречия / Only / Hardly /
    Scarcely / No sooner / Not only / Never / Rarely / Seldom — и за ним идёт
    aux до subject.
    """
    if len(doc) < 2:
        return False

    inversion_starters = {
        "never", "rarely", "seldom", "hardly", "scarcely", "barely",
        "no", "not", "only", "little", "nowhere", "neither", "nor",
    }

    first = doc[0].text.lower()
    if first not in inversion_starters:
        return False

    # Ищем порядок aux → subject в первых ~6 токенах
    for i, t in enumerate(doc[:6]):
        if t.dep_ in ("aux", "auxpass"):
            # subject должен идти после aux
            for child in t.head.children:
                if child.dep_ == "nsubj" and child.i > t.i:
                    return True
    return False


def detect_passive(doc) -> bool:
    return any(t.dep_ == "auxpass" for t in doc)

from grammar_assistant.tools.spacy_tools import analyze_sentence, _get_nlp
from grammar_assistant.models import StructureDiff


def compare_structures(text_a: str, text_b: str) -> StructureDiff:
    a = analyze_sentence(text_a)
    b = analyze_sentence(text_b)
    return StructureDiff(
        tense_changed=sorted(a.detected_tenses) != sorted(b.detected_tenses),
        tenses_before=a.detected_tenses,
        tenses_after=b.detected_tenses,
        inversion_changed=a.has_inversion != b.has_inversion,
        passive_changed=a.has_passive != b.has_passive,
    )


def lemmatize_and_compare(text_a: str, text_b: str) -> bool:
    nlp = _get_nlp()
    lemmas_a = [t.lemma_.lower() for t in nlp(text_a) if not t.is_punct and not t.is_space]
    lemmas_b = [t.lemma_.lower() for t in nlp(text_b) if not t.is_punct and not t.is_space]
    return lemmas_a == lemmas_b

def get_enabled_types() -> list[ExerciseType]:
    return [t for t, cfg in EXERCISE_REGISTRY.items() if cfg.enabled]


def pick_random_type() -> ExerciseType:
    enabled = [(t, cfg.weight) for t, cfg in EXERCISE_REGISTRY.items() if cfg.enabled]
    if not enabled:
        raise RuntimeError("No enabled exercise types")
    types, weights = zip(*enabled)
    return random.choices(types, weights=weights, k=1)[0]

import uuid
from pydantic_ai import Agent
from grammar_assistant.models import Exercise, ExerciseType

GENERATOR_INSTRUCTION = """
Generate a B2-level ERROR CORRECTION exercise.

Pick one common B2 grammar mistake from these categories (rotate):
- wrong tense (e.g., "I'm living here since 2020")
- wrong conditional form (e.g., "If I would have known...")
- article misuse (a/an/the/zero)
- subject-verb agreement
- preposition misuse
- gerund vs infinitive confusion
- word order

Build the exercise:
- instruction: "Find and correct the grammatical error in this sentence."
- prompt: ONE sentence containing exactly ONE clear error.
- expected_answer: the same sentence, fully corrected.
- grammar_topic: specific name of the rule violated.

The expected_answer MUST be grammatically correct (verify with check_grammar tool).
The prompt SHOULD contain a real error (do NOT call check_grammar on the prompt).
"""


def generate(agent: Agent) -> Exercise:
    result = agent.run_sync(GENERATOR_INSTRUCTION)
    ex = result.data
    ex.id = str(uuid.uuid4())
    ex.exercise_type = ExerciseType.ERROR_CORRECTION
    return ex

import uuid
from pydantic_ai import Agent
from grammar_assistant.models import Exercise, ExerciseType

GENERATOR_INSTRUCTION = """
Generate a B2-level CONDITIONALS exercise.

Pick ONE type randomly: Zero, First, Second, Third, or Mixed Conditional.
For Mixed prefer: past condition → present result.

Build the exercise:
- instruction: clearly state which conditional to use.
  Example: "Combine these two facts using a Third Conditional."

from pathlib import Path

model = GroqModel(config.llm_model, api_key=config.groq_api_key)

validator_agent = Agent(
    model=model,
    result_type=ValidationResult,
    system_prompt=_SYSTEM_PROMPT,
    retries=2,
)


@validator_agent.tool_plain
def check_grammar_tool(text: str) -> list[GrammarError]:
    """Check English text for grammar errors. ALWAYS call on user_answer first."""
    return check_grammar(text)


@validator_agent.tool_plain

    """Analyze grammatical structure: POS tags, tenses, inversion, passive voice."""
    return analyze_sentence(text)


@validator_agent.tool_plain
def compare_structures_tool(expected: str, user: str) -> StructureDiff:
    """Compare grammatical structures. Use for transformation exercises (tense/voice/reported speech/inversion)."""
    return compare_structures(expected, user)


@validator_agent.tool_plain
def lemmatize_compare_tool(a: str, b: str) -> bool:
    """Compare two sentences by lemmas (ignores casing/punctuation). Returns True if equivalent."""
    return lemmatize_and_compare(a, b)


@validator_agent.result_validator
async def ensure_explanation_quality(result: ValidationResult) -> ValidationResult:
    if not result.rule_name.strip():
        raise ValueError("rule_name must not be empty")
    if not result.explanation.strip():
        raise ValueError("explanation must not be empty")
    if not result.is_correct and not result.what_to_review.strip():
        raise ValueError("what_to_review must be filled when is_correct=False")
    return result

def get_fallback(exercise_type: ExerciseType) -> Exercise:
    pool = _FALLBACK.get(exercise_type, [])

        try:
            exercise = cfg.generator_fn(generator_agent)
            log_exercise_generated(exercise, regeneration_count=attempt, user_id=user_id)
            return exercise
        except Exception as e:
            log_assistant_error("generator", type(e).__name__)
            continue

    # Fallback
    exercise = get_fallback(target_type)
    log_exercise_fallback(target_type, reason="max_regenerations_exceeded", user_id=user_id)
    log_exercise_generated(
        exercise,
        regeneration_count=config.max_regeneration_attempts,
        user_id=user_id,
    )
    return exercise


def validate_answer(
    exercise: Exercise,
    user_answer: str,
    user_id: Optional[str] = None,
) -> ValidationResult:
    if not user_answer or len(user_answer) > 500:
        raise ValueError("user_answer must be between 1 and 500 characters")

    prompt = f"""
Exercise type: {exercise.exercise_type.value}
Grammar topic: {exercise.grammar_topic}
Instruction: {exercise.instruction}
Prompt: {exercise.prompt}
Expected answer: {exercise.expected_answer}
Accept alternatives: {exercise.metadata.get('accept_alternatives', [])}

User's answer: {user_answer}

Validate the user's answer using your tools. Follow the workflow strictly.
""".strip()

    try:
        result = validator_agent.run_sync(prompt)
        validation = result.data
        validation.exercise_id = exercise.id
        validation.user_answer = user_answer
        validation.correct_answer = exercise.expected_answer
        log_exercise_answered(exercise, validation, user_id=user_id)
        return validation
    except Exception as e:
        log_assistant_error("validator", type(e).__name__, exercise_id=exercise.id)
        raise


def submit_custom_exercise(
    user_sentence: str,
    exercise_type: ExerciseType,
    user_id: Optional[str] = None,
) -> Exercise:
    """
    Создаёт упражнение из предложения пользователя. НЕ валидирует входное
    предложение через LanguageTool (пользователь отвечает за корректность сам).
    expected_answer всё равно проверяется агентом.
    """
    prompt = (
        f"Use this sentence as the basis for the exercise: '{user_sentence}'. "
        f"Build a {exercise_type.value} exercise around it. "
        f"Do NOT check the user's input sentence for errors — accept it as given."
    )
    result = generator_agent.run_sync(prompt)
    exercise = result.data
    exercise.exercise_type = exercise_type
    exercise.id = str(uuid.uuid4())
    log_exercise_generated(exercise, regeneration_count=0, user_id=user_id, is_custom=True)
    return exercise

    "generate_exercise", "validate_answer", "submit_custom_exercise",
    "get_enabled_types",
]

В существующем routes.py / main.py:

    from fastapi import APIRouter, HTTPException
    from pydantic import BaseModel
    from typing import Optional
    from grammar_assistant import (
        generate_exercise, validate_answer, submit_custom_exercise,
    )
    from grammar_assistant.models import ExerciseType, Exercise, ValidationResult


    router = APIRouter(prefix="/grammar", tags=["grammar"])


    class GenerateRequest(BaseModel):
        exercise_type: Optional[ExerciseType] = None
        user_id: Optional[str] = None


    class ValidateRequest(BaseModel):
        exercise: Exercise
        user_answer: str
        user_id: Optional[str] = None


    class CustomRequest(BaseModel):
        user_sentence: str
        exercise_type: ExerciseType
        user_id: Optional[str] = None


    @router.post("/exercise", response_model=Exercise)
    def post_exercise(req: GenerateRequest):
        try:
            return generate_exercise(req.exercise_type, req.user_id)
        except Exception as e:
            raise HTTPException(500, str(e))


    @router.post("/validate", response_model=ValidationResult)
    def post_validate(req: ValidateRequest):
        try:
            return validate_answer(req.exercise, req.user_answer, req.user_id)
        except ValueError as e:
            raise HTTPException(400, str(e))
        except Exception as e:
            raise HTTPException(500, str(e))


    @router.post("/custom-exercise", response_model=Exercise)
    def post_custom(req: CustomRequest):
        return submit_custom_exercise(req.user_sentence, req.exercise_type, req.user_id)


В main.py:

    app.include_router(router)


Для Flask — те же три эндпойнта, адаптируй сигнатуры под Flask request body.

5.1. Импорт write_raw_logs
---------------------------
В файле grammar_assistant/logging_events.py я поставил placeholder:

    from your_logging_module import write_raw_logs

Замени your_logging_module на реальный путь к твоему модулю
(например, app.utils.logging или core.logger).


5.2. Llama 3.3 склонна к over-confidence
------------------------------------------
Несмотря на жёсткие правила в system prompt, модель иногда заявляет ответ
правильным без вызова check_grammar. Если такое поведение замечаешь часто:

- усиль формулировку в validator_system.md: "If you produce a response
  without calling check_grammar first, you have failed."
- добавь после run_sync принудительный вызов check_grammar и переписывание
  is_correct если есть ошибки. Это уже за пределами агента, на уровне
  обёртки в __init__.py — поправь validate_answer.


5.3. LanguageTool initialization
---------------------------------
При первом вызове check_grammar Java-процесс стартует ~3-5 секунд. На холодном
запуске первый вызов будет медленный. В FastAPI используй lifespan, чтобы
прогреть синглтон при старте приложения:

    from contextlib import asynccontextmanager
    from grammar_assistant.tools.language_tool import _get_tool, close_tool

    @asynccontextmanager
    async def lifespan(app):
        _get_tool()  # warm up
        yield
        close_tool()

    app = FastAPI(lifespan=lifespan)


5.4. Альтернативы — не идеально
--------------------------------
metadata.accept_alternatives — это руками заполненный список вариантов.
Для большинства упражнений лучше работает lemmatize_and_compare, чтобы
не зависеть от точной пунктуации. Валидатор уже это умеет.


5.5. Расширение fallback_bank
------------------------------
Сейчас по 1 упражнению на тип. Когда увидишь в логах event=exercise_fallback
часто — досыпь ещё 4-9 примеров каждого типа в _FALLBACK. Лучший источник
примеров — учебники B2 уровня (Murphy English Grammar in Use, Cambridge B2
First, Macmillan Open Mind B2).


5.6. detect_verb_tenses — эвристика, не идеал
-----------------------------------------------
Реализация в spacy_tools.py покрывает основные времена, но имеет края:
- Modal Perfect отдаётся как "Modal Perfect (must have V3)" одной строкой
- условные конструкции (would + V, would have + V3) метятся как Modal/Modal Perfect
  без понимания, что это часть conditional
- subjunctive (e.g. "I suggest he go") не детектируется

Для B2-валидации этого хватает: валидатор сравнивает структуру expected vs user,
и если набор времён совпал — задача transformation выполнена. Точную грамматику
дальше проверяет LanguageTool.


5.7. Аналитика по логам
------------------------
Когда накопится 50+ упражнений, можно отдельным скриптом построить из logs.jsonl:

- топ слабых тем (grammar_topic с самым высоким % is_correct=False)
- категории грамматических ошибок (grammar_error_categories)
- частоту фоллбэков по типам (видны слабые места генератора)

Это и есть твоё "форсирование пула" — берёшь топ-3 слабых темы и в
generate_exercise передаёшь конкретный exercise_type.


5.8. Pydantic AI версия
------------------------
Я писал под версии 0.0.14+. API стабилизируется, и в новых версиях возможны
небольшие переименования (например, result_type → output_type в каких-то
версиях, или tool_plain → tool). Если что-то падает на импорте — глянь в
актуальную доку: https://ai.pydantic.dev/
